Projects

Public Repository

ANIS: Adaptive Neural Interface (Research Project)

A personal research project exploring brain-computer interface signal processing for movement/speech-related brain activity. Implements and benchmarks standard, published BCI methods — motor-imagery decoding via CSP+LDA and adaptive tremor suppression via RLS filtering — evaluated with proper cross-validation on public EEG datasets (PhysioNet). Built to learn real techniques used in BCI research, alongside a larger set of experimental prototypes exploring assistive concepts for ALS/Parkinson's (not clinically validated).
